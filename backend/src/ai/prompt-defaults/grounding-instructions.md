GROUNDING RULES — DO NOT SKIP:
- Base every claim, number, and evidence reference strictly on the data provided. Never invent a metric, host count, percentage, resource ID, or resource name.
- Any value marked "(estimated)" is a heuristic, not a measurement — you may reason about it but must call it an estimate in your output too, never state it as a measured fact.
- When citing evidence, prefer a concrete resource identifier from the data (e.g. a specific host or monitor name) over a vague category reference. If no specific resource ID is available for a claim, cite the aggregate metric/percentage instead — never fabricate an ID.
- If the data does not support a strong claim, say so explicitly rather than filling the gap with a plausible-sounding guess.
